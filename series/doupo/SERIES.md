# 斗破苍穹 · 人物志

一集一个人物，一集一个问题。横屏，抖音和 B 站。**剧情以小说为准**，人物造型按漫画版。通用做法见仓库根目录 `SKILL.md`，这里只写这个系列自己的东西。

## 这个系列和权游系列不一样的地方

玄幻要的是压到最低再爆发：**画风要燃，打斗要顺**。不沿用权游的彩窗、家徽、绿先知片尾。

- 全片排成几次「压到最低再炸」，炸点卡在 BGM 的重拍上，炸之前音乐和画面先收住。
- 旁白字幕尽量少，只留台词、地点、招式名和非说不可的一两句。
- **镜头**：交代背景、叙事的段落用侧面；打斗和高潮才穿插别的机位（过敌人后脑勺、正面、主观视角、俯仰拍、特写），偶尔来几下，不为了花哨而切。

## 系列固定

| 项 | 做法 | 代码 |
|---|---|---|
| BGM | 沿用 `series/asoiaf/audio/bgm.mp3`（拍号见 `series/asoiaf/SERIES.md`）。片子比曲子短时在小节线上剪接 | 每集的 `mixfilm.py` 里的 `MAP` |
| 片尾署名 | 穿斗篷、看不见脸的码点小人盘坐在药鼎前，炉火是本集人物的火色，最后变色。两行字：「码点小人 / 炉火未熄，下一集见。」 | 现在在 `ep01_xiaoyan/film.py` 的 `s_sign()`，第二集用到时提到系列目录 |
| 招式名 | 毛笔大字砸出来（`fonts/MaShanZheng-Regular.ttf`，OFL 许可） | `action.Slam` |
| 漫画分格 | 黑底白边的斜格，一拍砸进来一格 | `fx.panels()` |
| 火烧转场 | 换场时一条火线烧穿画面，火色是人物当时手里的火 | `fx.burn()` |
| 等级牌 | 左上角一块小石碑写着人物现在的等级，升级时翻牌 | `fx.badge()` |
| 出场名牌 | 重要人物第一次出场：斜黑条、毛笔名字、身份、一道火色 | `fx.tag()` |
| 绝招命中 | 那一帧变成黑白墨稿定格，配拟声大字（「轰」「锵」） | `fx.ink()` |
| 佛怒火莲 | 三层花瓣一拍开一层，命中时花瓣飞散 | `fx.lotus()`、`fx.petals()` |
| 翅膀 | 紫云翼是紫黑的实体翼；斗王以上是斗气化翼（半透明，颜色随人） | `fx.wing()` |

还没定的：封面版式。
