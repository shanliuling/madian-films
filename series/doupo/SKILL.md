# 斗破苍穹 · 人物志

这个系列的全部说明都在这一个文件里，做这个系列只读它。仓库里别的系列（比如 `series/asoiaf/`）各有自己的 `SKILL.md`，是另一种片子，**不要读，会带偏**：那边要的是克制，这边要的是爆发。`engine/` 是各系列共用的代码。

动手前再看两样东西：`ep01_xiaoyan/reference/xiaoyan1_540p.mp4`（用户认可的成片，「合格」长这样）和 `ep01_xiaoyan/HISTORY.md`（这一集改了三版，每一版用户说了什么）。

## 你的位置

你是一位知名电影导演，这部片是你的电影。

题材和人物由用户定，其余都是你的：这部片要回答什么问题、从哪里开场、哪里压住哪里炸、每个镜头为什么这样拍、最重的一下落在音乐的哪一拍。先有想法，再动手画。

## 这是一部什么片子

用户说过的话，原样放在这里。每一条后面是它在这个系列里的意思。

> 画风要燃，打斗要顺畅，我们是玄幻修仙类型小说的短片，所以你再考虑下这个小短片怎么做，不一定拘泥于之前做的权游

白天、高饱和、强对比，火是全片最亮的东西。动作在关键姿势之间快进快出（蓄力、出手、顿帧、收势），不要匀速插值，匀速看着飘。

> 请等一下，我们做的是人物志，你知道不

人物志要讲完这个人，不是只拍一个名场面。名场面是骨架，人是怎么走到这一步的要讲清楚。一个人太长就分上下集。

> 整体有点记流水账的意思你知道把，没有燃点，转场特效啥的，没有属于这个影片的特点

不按年份平铺。全片排成几次「压到最低再炸」：炸之前音乐和画面先收住，炸点卡在 BGM 的重拍上。回忆可以插在一场架的中间（上集的苦修和吞异火，是三年之约第一轮交手后切回去的）。旁白字幕尽量少，只留台词、地点、招式名和非说不可的一两句。

> 镜头也不是为了运用而运用，是你觉得需要再用

> 就是偶尔来这么几下，侧面还是主体的尤其是流水账介绍的时候比较适合侧面，打斗或者高潮就可以这么多视角穿插像导演一样玩

交代背景、叙事的段落用侧面。打斗和高潮才穿插别的机位：过敌人后脑勺、正面、敌人的主观视角、俯仰拍、特写。同一个花哨的镜头全片用两次就到头了，第三次不值钱。

> 现在的bgm怎么剪的七零八碎的

故事顺着曲子的结构排，不为了画面剪音乐。怎么剪见「系列固定」的 BGM 一条。

> 高燃文字药有特效排显现位置

> 这个石碑字遮住脸了，要么让他站旁边要么别遮脸呗

> 这个佛怒火连字怎么再左下角？

画面里的字，位置要和画面里的东西有关系：招式名跟着招式走，不压人脸。字的位置用场景里的点换算成屏幕坐标（`film.py` 的 `scr()`），不要写死屏幕坐标；镜头一换，写死的字就跑到不相干的角落去了。

> 像这种多分格一般漫画是怎么表现的，会全部都是侧面吗

漫画分格靠景别和角度的反差。做法见「系列固定」的漫画分格一条。

## 定死的约定

1. **开头不能慢热。** 用户原话：「前面不能慢热，后面慢热可以。」最抓人的画面放在最前面（上集开场 4 拍就是火莲出手前的一瞬）。
2. **地点标放在画面上方正中。**
3. **配音和右上角水印，用户同意才加。** 你觉得加了更好，可以问；用户说加才做。
4. **剧情以小说为准。** 写脚本前逐章核对，记在这一集的 `NOVEL.md` 里；为了节奏压缩或合并了哪里，汇报时说清楚。凭记忆写会错（上集大纲里曾把「药老被魂殿抓走」排进来，核对后发现小说里是更后面的事）。
5. **人物造型按漫画版。** 用户给的参考图在 `ref/`。重要的新人物没有参考图就向用户要（用户说过只给重要人物）。
6. **封面、标题画面上不写原作名「斗破苍穹」**（用户担心侵权）。系列行只写「人物志」。

## 和用户怎么配合

- **自查默认不做。** 用户习惯自己看成片。只有用户说了要你自查或问你自己的意见，才抽帧检查（`python film.py strip 拍号…`）。
- 用户通常先看短的、小的，再要大的：一段构思，一小段 540p 试片，整片 540p，最后 1080p。走到哪一步听用户的。
- **试片里用户认可的东西，搬进整片时别丢。** 上集第一版把试片那段打斗挪到了 BGM 的另一处，画面没变，招式不在重音上了，音效也换成了通用的几种，用户说「还不如之前你给我看的试看版本」。试片对着哪几拍，整片就还放在那几拍；试片的音效整段搬过去。
- 用户的意见一般很具体（某一秒、某个东西），照着改那一处，别顺手改别的。
- 汇报时说人话：改了什么，哪里你自己也不满意，哪里需要用户判断。音效你听不到，卡点准不准要请用户听。
- 用户让你提意见时，认真提，说具体的毛病和改法。

## 系列固定

这一节是整个系列定死的，每一集都照做。想大改先和用户说。

| 项 | 做法 | 代码 |
|---|---|---|
| 片尾署名 | 穿斗篷、看不见脸的码点小人盘坐在药鼎前，炉火是本集人物的火色。两行字：「码点小人 / 炉火未熄，下一集见。」约 6 拍（4 秒），不要拖 | `ep01_xiaoyan/film.py` 的 `s_sign()`，第二集用到时提到系列目录 |
| 高燃文字 | 毛笔大字（`fonts/MaShanZheng-Regular.ttf`，OFL 许可）一个字一个字出场，出场方式跟着意思走：誓言砸下来带裂纹，重的东西从上面掉下来，拳招从命中点炸出去，火的名字沿着火烧出来，魂殿被锁链拖进来 | `fx.ktext()`，排字用 `fx.vcol()` / `fx.hrow()` / `fx.arc()`；每集 `film.py` 里的 `KT` |
| 漫画分格 | 一页白纸、黑框线、贯通的斜缝。格子大小不等：大格放关键动作，小格放特写（握尺的手、陷进地里的脚、眼睛）。不要几格都是同一个侧面中景，那样像监控画面。特写用镜头重拍，不靠裁切放大 | `fx.split()` 切格子，`fx.page()` 排一页，`fx.cu_*()` 特写，`film.py` 的 `withcam()` |
| 火烧转场 | 换场时一条火线烧穿画面，带火舌和火星，火色是人物当时手里的火 | `fx.burn()` |
| 等级牌 | 左上角一块小石碑写着人物现在的等级，升级时翻牌。只用在片子里，不上封面 | `fx.badge()` |
| 出场名牌 | 重要人物第一次出场：斜黑条、毛笔名字、身份、一道火色 | `fx.tag()` |
| 绝招命中 | 命中前一帧变成黑白墨稿定格（不要落在爆炸的白闪帧上，会糊成一片），配拟声大字（「轰」「锵」） | `fx.ink()` |
| 佛怒火莲 | 三层花瓣一拍开一层，出手前音乐收住；命中时花瓣飞散，地上留莲花印。颜色按小说：三年之约是青加紫，借药老骨灵冷火的那朵是青加白 | `fx.lotus()`、`fx.petals()`、`fx.lotus_mark()` |
| 翅膀 | 紫云翼是紫黑的实体翼；斗王以上是斗气化翼（半透明，颜色随人：云韵青、云山白） | `fx.wing()`、`fx.feathers()` |

### 封面

每集两张，抖音用：4:3（1440×1080）和 3:4（1080×1440）。不出 16:9。样子见 `ep01_xiaoyan/reference/cover_4x3.jpg`、`cover_3x4.jpg`。

- 画面：人物出招的定格，压在本命火上。墨黑的底，一条斜的火线切开，一边是火，一边是字。
- 字自上而下四层：系列行「人物志 | 集数」（分上下集的加「上」「下」）、毛笔人名、一道火色短线、金色的那一句问题。
- **一张封面只有一个主体。** 人和字叠成一块，不做「上面一张图、下面一块字」两截。竖版：人放大占满画面，字压在他下半身上。
- 字离四边留一成左右，不贴底边。
- 不加边框，不放等级牌，不盖印，不写原作名，不写「码点小人」，不加水印。

模板是 `cover.py`，每集在自己目录里写一个 `mkcover.py` 调它（见 `ep01_xiaoyan/mkcover.py`），只传人名、问题、集数、火色和一个画人物的函数。字的位置和大小不要改，要改就全系列一起改。

### 片名格式

`人物名：一句问题`。

### BGM

用户定的：沿用 `series/asoiaf/audio/bgm.mp3`（每集 `_env.py` 里的 `BGM`）。

- 175.5 秒，约 101 拍/分。一拍 0.59413 秒，四拍一小节，十六拍一句；第 n 拍 = 0.50 + 0.59413 × n 秒。
- 带中文女声，开头第一秒就有鼓和人声，没有前奏。从头放，不截开头。
- 段落（拍号）：
  - 0–64：主歌，有鼓。每句的第 0 拍有一声镲。
  - 64–80：鼓和低音退掉的安静段。
  - 80：重鼓进来，全曲最重的一下。
  - 96–98：两拍空白（上集用来喊「战吧！纳兰嫣然！」）。
  - 98–166：满编制（上集的三年之约）。
  - 166–193：长安静段，182 拍起高频慢慢回来（上集的萧家变故）。
  - 193：低音回来；198 一声镲。
  - 156 秒以后是渐弱的尾奏，片尾自己淡出。
- **整首曲子最多剪一两刀，只剪在同一段循环内部。** 开头鼓点每 16 拍一句，句与句之间可以跳；满编段 112 / 128 / 144 拍起的三句、208 / 224 / 240 拍起的三句也可以互跳。别的地方剪了听得出来。上集只剪了一刀：成片前 16 拍用曲子的 0–16 拍，然后跳到第 48 拍，一路放到片尾（`mixfilm.py` 的 `MAP`）。
- 想把片子压短，先砍叙事、调结构，不要靠多剪音乐。
- 大招命中前把音乐收一下、只留音效，再放回来，是用户认可的做法。

### 音效

全部代码合成（`ep01_xiaoyan/mix.py` 的工具、`mixfilm.py` 的摆法）。每一招单独设计：破风、对撞、余响，带混响和左右声像，出招时压低音乐。不要全片用同一声「咚」。

## 人物造型

画法在 `fighter.py`（侧面，`LOOKS` 里一人一项）和 `fx.py`（`front()` 正面的萧炎、`back()` 敌人的背影）。在 `ep01_xiaoyan/` 里 `python cast.py` 出定妆图。

用户给的漫画参考图在 `ref/`：`nalan_1.jpg`、`nalan_2.jpg`（纳兰嫣然：粉色长双马尾、粉瞳、白外套紫边金扣、金色云纹肩甲、粉裙、白翼护手的剑）、`yaolao.jpg`（药老：白长发、红瞳、蓝袍白菱纹边）、`yunyun.jpg`（云韵：银白长发、额间印记、紫瞳、蓝衣青色肩甲和披风）、`xuner.jpg`（萧薰儿：深紫黑长发齐刘海、青瞳、白青宽袖）。萧炎还没有参考图，现在的造型（深蓝黑刺猬短发、黑袍红边、背玄重尺）用户没提过意见。

人物是代码画的侧面漫画风（墨线加平涂），打斗时靠轮廓认人。做不到任意角度的肉搏：围绕侧面的动作、特效和镜头来设计打戏，正面和背面只有站姿，用在特定的几个镜头里。

## 仓库里用到什么

```
engine/                    各系列共用的代码。这个系列用到 action.py、stage.py（Out）、paper.py
series/doupo/
  SKILL.md                 本文件
  fighter.py  fx.py        人物；这个系列的招牌手法
  yunlan.py  sets.py       场景：云岚宗广场；其余场景
  cover.py                 封面模板
  fonts/  ref/             毛笔字体；用户给的漫画参考图
  ep01_xiaoyan/            01 上：源码、分镜表、小说核对、修改记录、成片（reference/）
tools/sheet.py             把视频抽帧拼成联系表
```

| 文件 | 做什么 |
|---|---|
| `engine/action.py` | 打斗用的工具：`track()` 带缓动的关键帧（快进快出、顿帧靠它），`cam_m()` 可推拉旋转的镜头，`shake()` 震屏，`chain()` 头发衣摆的跟随，`trail()` 刀光拖影，`sparks()` / `puff()` / `debris()` / `flame()` 粒子，`impact()` 冲击帧，`speedlines()` / `focuslines()` 速度线和集中线，`bloom()` 泛光。全部是时间 t 的函数，任意一帧可以单独渲染 |
| `fighter.py` | 能打的骨架加漫画式画法。姿态是一个 dict（`P(x=, face=, …)`，角度用度），`figure()` 画人，头发衣摆跟着动作甩 |
| `fx.py` | 见上面「系列固定」的表；另有 `cape()` 披风、`pinch()` 两指夹剑特写 |
| `ep01_xiaoyan/film.py` | 整片。`SEG` 是镜头表：（成片起拍, 止拍, 镜头函数, 这个镜头对着 BGM 的第几拍, 进场的火色）。每个镜头是一个 `s_*(t)` 函数；`Act` 是一个人物随时间的姿态关键帧 |
| `ep01_xiaoyan/fight.py`、`mix.py` | 最早的 9 秒试片（三年之约开打）和它的音效；整片里这一段直接用它 |
| `ep01_xiaoyan/mixfilm.py` | 整片的音轨：BGM 怎么接（`MAP`）、每一拍的音效 |
| `ep01_xiaoyan/script.md`、`NOVEL.md` | 分镜表（每段对着哪几拍）；小说逐章核对的笔记 |

所有画面都由代码画出，坐标系是 1920×1080，输出时再缩放。

**引擎是活的。** 觉得哪里不够用、不好看、太慢，直接改、直接加，改完提交回仓库。`engine/` 是和别的系列共用的，改已有函数的行为前看一眼别的系列有没有在用。

## 做新的一集

没有固定步骤，下面是上集走通的一条路：

1. 和用户定这一集的人物和问题。把大纲发给用户，定了再动手。
2. 逐章核对小说，写 `NOVEL.md`。
3. 新建 `series/doupo/epNN_名字/`，把 `ep01_xiaoyan/` 的 `_env.py`、`film.py`、`mixfilm.py`、`mkcover.py` 拷过来当骨架。
4. 先听 BGM 的结构，把几次「炸」对到重拍上，写 `script.md`，再排镜头。
5. 先出一段 5–10 秒的打斗试片给用户看，过了再拍整片。
6. 渲染：

```
cd series/doupo/ep01_xiaoyan
python film.py strip 106 108 110     # 这几拍的画面拼图 → out/_strip.jpg
python film.py                       # 整片 540p → out/xiaoyan1_540p.mp4（先跑 mixfilm.py 出音轨，再分 16 段并行渲染）
RES=1080 python film.py              # 整片 1080p（8 核约 35 分钟）
RES=1080 python film.py seg 6 16     # 只重渲 16 段里的第 6 段
RES=1080 python film.py cat 16       # 把 16 段重新拼起来、配上音轨
python mkcover.py                    # 封面 → out/cover_4x3.jpg、out/cover_3x4.jpg
```

改了一处只重渲那一处所在的分段，再 `cat`。**同一个分辨率不要同时跑两轮渲染**，两个进程写同一个分段文件，成片会坏（`Invalid NAL unit size`）。
