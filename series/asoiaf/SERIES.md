# 冰火人物志（系列名暂定）

《冰与火之歌》人物视角的系列短片。**一集一个人物，一集一个问题**，不按年份讲生平。基调严肃、克制，是悲剧，不搞笑。

片名格式：`人物名：一句问题`。例：《奈德·史塔克：最重荣誉的人，为什么第一个死》。

| 集 | 人物 | 这一集要回答的问题 | 状态 |
|---|---|---|---|
| 01 | 奈德·史塔克 | 最重荣誉的人，为什么第一个死？ | 已完成，`ep01_ned/` |
| 02 | 罗柏·史塔克（少狼主） | 一仗没输过的人，怎么输掉了一切？ | |
| 03 | 泰温·兰尼斯特 | 打败了所有敌人，谁打败了他？ | |
| 04 | 培提尔·贝里席（小指头） | 一个小领主，怎么搅乱了七国？ | |
| 05 | 史坦尼斯·拜拉席恩 | 最讲原则的人，怎么走到烧死女儿那一步？ | |

问题只是起点。这一集真正的答案是什么、用什么画面说出来，由导演定。第一集的答案是：他不是不懂权力的游戏，只是每一次都不肯拿孩子下注。

## 固定的东西

**BGM：`audio/bgm.mp3`，整个系列都用这一首。**
- 141.9 秒，约 149.5 拍/分。一拍 0.4014 秒，四拍一小节，一小节 1.6056 秒；第 i 小节起点 = 0.05 + 1.6056 × i 秒。
- 带中文女声的电音，偏振奋，不悲壮。全程响度很平，鼓一直在，没有天然的安静段。
- 低音空一拍的地方：32.2 秒（小节 20）、45.0 秒（小节 28）；72.3 秒（小节 45）回到开头的段落。
- 需要停顿时自己在混音里做。第一集的做法是剑落时音乐带余响停住约 2.4 秒，只留合成音效，下一小节渐入（见 `ep01_ned/mix.py`）。

**片尾署名：`endcard.py`。** 绿先知穿斗篷坐在鱼梁木树根里，三眼乌鸦停在膝头，第三只眼睁开，灯挂在树枝上。旁边三行字：

```
码点小人
长夜黑暗，我替你提灯。
下一集｜（下一集的人物）
```

**配音和水印**：第一集都没有。要加先问用户。

## 系列的「长相」

第一集定下来、用户认可的样子：
- 暗调的侧面人物，靠轮廓光和动作演戏（`engine/tallfig.py`、`engine/stage.py`）。
- 彩窗（`engine/glass.py`）。第一集里它代表「后人怎么记住这个人」。
- 被灯照亮的羊皮纸沙盘地图（`westeros.py`），海岸线来自用户给的参考图。
- 金色大字只给台词和结论，小字幕讲事。

这些是让观众认出「这是同一个系列」的东西。每一集的母题、色彩、镜头、结构都可以完全不同；这几样想大改时，先和用户说一声。
