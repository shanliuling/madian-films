# 权力的游戏 · 人物志（系列名暂定）

这个系列的全部说明都在这一个文件里，做这个系列只读它。仓库里别的系列（`series/` 下的其他目录）各有自己的 `SKILL.md`，是另一种片子，不用读。`engine/` 是各系列共用的代码。

## 你的位置

你是一位知名电影导演，这部片是你的电影。

题材和人物由用户定，其余都是你的：这部片要回答什么问题、从哪里开场、用什么画面贯穿全片、颜色怎么随剧情变、每个镜头为什么这样拍、哪里快哪里慢、最重的一下落在音乐的哪一拍。先有想法，再动手画。

用户说过的话，原样放在这里：

> 不是让你复刻他镜头啥的，而是让你像一个导演一样，这每部影片就相当于你的电影。

> 我们的画面好像都是剪影图片？怎么没看见他动起来呢，多来点镜头语言呀，多来点想象力好吧。

> 为什么感觉这种影片看着有点无聊啊，像流水线，记录流水账一样。

所以：别按年份平铺，人要真的动，镜头要有想法。怎么做到，你自己决定。`series/asoiaf/ep01_ned/` 是一部做完并被用户认可的片子，可以看它是怎么想的、怎么写的，不必照它的结构来。

## 三条约定

只有这三条是定死的：

1. **开头不能慢热。** 用户原话：「前面不能慢热，后面慢热可以。」最抓人的画面和悬念放在最前面。
2. **地点标放在画面上方正中。**
3. **配音和右上角水印，用户同意才加。** 你觉得加配音会更好，可以问；用户说加才做。水印同理。

这个系列另有自己固定的东西（封面版式、家徽、片尾署名、BGM 等），写在下面「系列固定」一节，那一节也要照做。

## 和用户怎么配合

- **自查默认不做。** 用户习惯自己看成片。只有用户事先说了要你自查，才抽帧检查（`film.py strip`、`tools/sheet.py`）。
- 用户通常先看短的、小的，再要大的：一段构思，一小段 540p 试看，整片 540p，最后 1080p。走到哪一步听用户的，用户说直接出 1080p 就直接出。
- 用户的意见一般很具体（某一秒、某个东西），照着改那一处，别顺手改别的。
- 汇报时说人话：改了什么，哪里你自己也不满意，哪里需要用户判断。音效你听不到，要请用户听。

## 仓库里有什么

```
engine/                通用模块，各系列共用
series/asoiaf/         这个系列：SKILL.md（本文件）、BGM、维斯特洛地图、家徽、封面模板、片尾署名
  ep01_ned/            第一集完整源码、文案、修改记录、成片（reference/）
tools/sheet.py         把视频抽帧拼成联系表（用户要求自查时用）
```

| 文件 | 做什么 |
|---|---|
| `engine/stage.py` | 核心。`Scene`：分层视差背景 + 每帧用 cairo 画人 + 每帧打光；`kf()` 关键帧插值；`pose()`/`walk()` 姿态插值和走路循环；`Shatter` 把一张图碎成几百片（时间倒着给就是拼回去）；`Out(w, h)` 输出分辨率 |
| `engine/tallfig.py` | 写实比例的侧面人物：`fig(c, x, y, H, 造型, 姿态, 朝向, P=关节角度)`，`sword()`；`CAST` 是已有角色的造型表 |
| `engine/bighead.py` | 侧面大特写的脸 |
| `engine/looks.py` | 轮廓光、颗粒、暗角、光柱、发光字 |
| `engine/glass.py` | 彩窗：`window()` 画一扇尖拱彩窗，`wall()` 把几扇嵌进石墙 |
| `engine/scene.py` | 布景件：大圣堂剪影、城市天际线、前景人群、飞鸟 |
| `engine/txt.py` | 字幕和大字：`Titles`，按时间出字，带缓存 |
| `engine/paper.py` | cairo 画布、字体、纸纹 |
| `series/asoiaf/westeros.py` | 维斯特洛地图：`texture()` 贴图，`pview()` 倾斜沙盘视角，`XY()` 地点坐标，`smoothline()` 平滑路线 |
| `series/asoiaf/endcard.py` | 片尾署名画面：绿先知和三眼乌鸦 |

所有画面都由代码画出，坐标系是 1920×1080，输出时再缩放。

**引擎是活的。** 觉得哪里不够用、不好看、太慢，直接改、直接加，改完提交回仓库，下一集就能用上。唯一提醒：人物造型、彩窗、片尾署名是一个系列的「长相」，同一个系列里想大改，先和用户说一声。

## 做新的一集

没有固定步骤，下面只是能跑通的一条路：

1. 读下面的「集数」和「系列固定」，知道这一集是谁、BGM 怎么分段。
2. 查资料，想清楚这部片。把构思发给用户。
3. 新建 `series/asoiaf/epNN_名字/`。可以把 `ep01_ned/` 里的 `_env.py`、`film.py`、`mix.py` 拷过来当骨架，也可以自己重新组织。
4. 时间线按 BGM 的拍子排（拍长、起点和段落写在「系列固定」的 BGM 一条里）。
5. 音轨在 `mix.py` 里合成：BGM 加代码合成的音效。BGM 没有安静处时，在最重的那一下让音乐停住、只留音效，是用户认可过的做法。
6. 渲染：

```
cd series/asoiaf/ep01_ned
python film.py clip 0 10          # 前 10 秒，540p，带音轨 → out/clip_540p.mp4
python film.py full               # 整片 540p → out/ned_540p.mp4（8 核约 3 分半）
RES=1080 python film.py full      # 整片 1080p
python film.py strip 0.5 22 75.5  # 这几个小节处的画面拼图 → out/_strip.jpg（自查时用）
```

`ep01_ned/film.py` 里能找到这些写法：镜头表 `SHOTS`（起止小节、哪场戏、镜头关键帧、时钟）、倒放的镜头、地图上平滑移动的路线和跟拍、俯拍长矛围成一圈、斜线分屏、闪白和震动、字幕表。`baelor.py` 是一场完整的戏：布景、每个人物随时间的动作、镜头表、真人戏凝成彩窗再碎裂。

## 这个系列

《权力的游戏》人物视角的系列短片。对外（封面、标题）用「权力的游戏」，看剧知道这个故事的人比读过原著的多；「冰与火之歌」放在标题后半段和话题标签里。**一集一个人物，一集一个问题**，不按年份讲生平。基调严肃、克制，是悲剧，不搞笑。

## 集数

片名格式：`人物名：一句问题`。例：《奈德·史塔克：最重荣誉的人，为什么第一个死》。

## 系列固定

这一节是整个系列定死的，每一集都照做。别的都由导演决定。

### 1. 封面
每集一张封面，版式全系列一样，主页上排在一起一眼看得出是同一个系列：
- 主角的彩窗像（`engine/glass.py` 的画法），占画面主体。
- 主角的家徽放大压暗，铺在右半边的字后面当底纹；四周是家族色的边框。
- 封面上不写箴言，不写「码点小人」，不加水印。
- 字的位置和字体每集不变：系列名「权力的游戏」加集数、人物名、那一句问题。
- 每集出三张：16:9（1920×1080）、4:3（1440×1080）、3:4（1080×1440，彩窗在上、字在下居中）。抖音要 4:3 和 3:4 两张。

模板是 `cover.py`，每集在自己目录里写一个 `mkcover.py` 调它（见 `ep01_ned/mkcover.py`），只传家族、人物名、问题、集数、主角的彩窗和画幅。

### 2. 片名格式
`人物名：一句问题`。

### 3. 家徽
按原著的描述自己画，不用 HBO 剧集的官方徽章图。全系列共用同一套画法，同一个家族在每一集里长得一样。

画好的在 `heraldry.py`：`sigil(家族, 尺寸, shape)`，`shape` 有盾形（封面、正面）、圆章（名字旁）、旗（地图上，`wave()` 让它飘）。`python heraldry.py` 出一张总览。要用到还没画的家族，照同样的画法加进去。

### 4. 家族色
见下面的表。全系列通用。只用在点缀上：名字旁的小家徽、台词的描边和光晕、地图上的旗、封面边框。正文字体和大小不变，全片的色彩设计仍由导演定。

### 5. 人物出场
人物第一次出场时，名字旁带一枚小家徽。现成的是 `housefx.nametag()`。

### 6. 地图
势力和军队用家徽旗表示：`heraldry.flag(画面, 家族, x, y, 旗高, t, grow, crown)` 画一面插在地图上的旗，`grow` 是升旗，`crown=True` 在杆顶加王冠（称王的人）。旗沿路线走，路线退成旗后面一条家族色的线。

### 7. 片尾署名页
`endcard.py`：绿先知穿斗篷坐在鱼梁木树根里，三眼乌鸦停在膝头，第三只眼睁开，灯挂在树枝上。旁边两行字：

```
码点小人
长夜黑暗，我替你提灯。
```

下一集的预告不写人物名字，只在画面里藏一枚下一集人物的家徽，让观众自己认。藏在哪里、怎么藏由导演定。`greenseer(..., hide=家族)` 是第一集的藏法：家徽在字后面的黑暗里，第三只眼睁开时闪一下，之后只剩很淡的影子。

### 8. BGM
`audio/bgm.mp3`，整个系列都用这一首，从头放，不截开头（开头有人声，截了会切掉字）。
- 175.5 秒，约 101 拍/分。一拍 0.59413 秒，四拍一小节（2.3765 秒），十六拍一句；第 n 拍 = 0.50 + 0.59413 × n 秒。
- 带中文女声，开头第一秒就有鼓和人声，没有前奏。
- 段落（拍号 / 秒）：
  - 0–64 拍（0.5–38.5 秒）：主歌，有鼓。每句的第 0 拍有一声镲。
  - 64–80 拍（38.5–48.0 秒）：鼓和低音退掉的安静段。
  - 80 拍（48.0 秒）：重鼓进来，全曲最重的一下。
  - 96–98 拍（57.5–58.7 秒）：两拍空白。
  - 98–166 拍（58.7–99.1 秒）：满编制。
  - 166–193 拍（99.1–115.2 秒）：鼓、低音、高频一起退掉的长安静段，182 拍起高频慢慢回来。
  - 193 拍（115.2 秒）：低音回来；198 拍（118.1 秒）一声镲。
  - 156 秒以后是渐弱的尾奏，两分钟的片子用不到，片尾自己淡出。
- 第一集的用法（`ep01_ned/film.py` 的 `RETIME` 表）：开场剑落在第 4 拍，片名在第 14 拍；第一个安静段放「国王北上、翻族谱」，80 拍的重鼓给「孩子的真相」；全片最重的剑落放在 166 拍，之后的沉默和余波用音乐自己的安静段，193 拍鼓回来接「五个国王」。这是一种用法，不是规定；每集把自己最重的一下对到哪里由导演定。
- 剑落那一下，混音里仍让音乐带余响停住约 2.4 秒、只留合成音效，再渐入（见 `ep01_ned/mix.py`）。

### 9. 配音和水印
第一集都没有。要加先问用户。

> 现状：家徽库、封面模板、人物名牌、片尾藏家徽、地图上的家徽旗（`heraldry.flag()`）都已经有代码。第一集有三种画幅的封面，片名页的字后面也垫了一枚压暗的狼头（和封面一个样子），片尾藏的是史塔克的冰原狼，四段地图都用家徽旗（做法见 `ep01_ned/film.py` 的 `map1`、`map3`、`map4`）；人物出场的小家徽第一集还没用。地点的小图标（城堡、双塔等）和事件记号（旗倒下、旗烧掉）还没有做。

## 可以用的点子

不是规定，用不用、怎么用看这一集讲什么：
- **箴言当台词用**：不放在开头当装饰，放在转折的那一刻。
- **箴言和家族台词的专属字效**：`housefx.motto()`。「凛冬将至」结霜飘雪，「听我怒吼」金字砸下带一圈冲击波，「兰尼斯特有债必还」熔金往下滴、金币落下，「怒火燎原」字后面起火。别的家族默认只是家族色的字加圆章。一集里用一两次就够，多了就不值钱了；要给新的家族加字效，取它最有代表性的一样东西，别堆。
- **同一件事换一个人看**：奈德被砍头，在罗柏那一集是一封渡鸦送来的信；红色婚礼，在泰温那一集是他写信的那只手。
- **原著彩蛋**：比如被鹿角刺死的母冰原狼。不解释，留给懂的人在评论区说。
- **渡鸦送信做转场**：换地点时一只渡鸦飞过去，和片尾的三眼乌鸦呼应。
- **结尾留一个问题**给评论区。

## 系列的「长相」

第一集定下来、用户认可的样子：
- 暗调的侧面人物，靠轮廓光和动作演戏（`engine/tallfig.py`、`engine/stage.py`）。
- 彩窗（`engine/glass.py`）。第一集里它代表「后人怎么记住这个人」。
- 被灯照亮的羊皮纸沙盘地图（`westeros.py`），海岸线来自用户给的参考图。
- 金色大字只给台词和结论，小字幕讲事。

这些是让观众认出「这是同一个系列」的东西。每一集的母题、色彩、镜头、结构都可以完全不同；这几样想大改时，先和用户说一声。
