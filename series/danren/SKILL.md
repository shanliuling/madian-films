# 战局地图 + 阵战 + Q 版人物 工具包（mapwar）

一套 Python 工具，把一段战争史做成卡点短片（1920×1080 / 30fps），全部画面由代码画出，不用生图：
- **地图**：真实地理底图上，势力颜色随城池一座座易手而蔓延；军队是一簇簇蛋蛋兵（或火柴小人），人数随兵力增减。
- **战场**：垂直俯视的兵种阵型战，或斜视角的大头兵（"蛋蛋兵"）撞阵、对射，把"这一仗是怎么打赢的"演出来。
- **人物**：有关节、有表情、可换装的 Q 版角色，能站能跑能骑马，也能做空翻下劈这类动作戏、相拥跪地这类情感戏，和正面大头特写。

## 两种时代风格

同一套地图、人物、战场模块，按题材换"穿什么、拿什么、仗怎么打"：

| | 古代蛋蛋（示例 `examples/chuhan_q`） | 近现代蛋蛋（示例 `examples/sidu`） |
|---|---|---|
| 地图上的军队 | `sc['egg']`：`hat='ancient'` 头盔盔缨，`weapon='spear'/'ji'`，骑兵（`cav=1`）骑小马 | `sc['egg']`：`hat='bajiao'/'helmet'/'junmao'/'strawhat'`，背枪 |
| 斜视角战场 | `eggfield` 默认：长枪/戟方阵、楔形骑兵撞阵、溃逃 | `eggfield.set_looks()` 换军装和 `weapon='rifle'`；`fire` 开火、`dao` 大刀冲锋、`crouch` 蹲在掩体后；`eggfx` 画战壕、沙包、曳光弹、炮弹爆炸、弹坑、手榴弹、飞机、浮桥、木船 |
| 俯视战场 | `field`：阵型、骑兵凿穿、四面合围 | 可用地图箭头和斜视角战场代替；需要时自己加兵种 |
| Q 版人物 | 演义戏曲扮相：铠甲、靠旗、冠冕、长袍 | `uniform` 军装、`puttee` 绑腿、草鞋、军帽、`modern_hair`、披风、步枪 |

具体选哪些镜头、怎么配，按题材判断；两部示例都是成片，用来看写法。

**这份说明给的是能力和做法，不是固定模板。** 题材、地图范围、镜头数量、每场仗怎么打、开头怎么抓人，都按题材自己判断。`examples/` 里是做完的片子，用来看写法，不要照抄结构。

## 0. 准备

本 skill 文件夹就是完整工具包：`mapwar/` 代码、`cast/` 角色库、`tools/` 脚本、`examples/` 示例、`references/` 参考、`data/` 地理数据（精简版不含 data，需要先运行 setup_data）。命令都在本文件夹下运行。

```
pip install numpy opencv-python pycairo pillow scipy        # 另需 ffmpeg 在 PATH 里
pip install edge-tts                                        # 只有要配音时才需要（在线语音，要联网）
python tools/setup_data.py                                  # data/ 里缺文件时才需要：下载地理数据（约 60MB）
```
- 字体：需要一个粗宋体/黑体。默认会找 Noto Serif CJK Bold、Windows 的宋体/雅黑、macOS 宋体；都没有就设环境变量 `MAPWAR_FONT=字体文件路径`。
- 看任意范围的空底图：`python tools/basemap.py 西经 东经 南纬 北纬 [每度像素] out.jpg`
- 看角色库定妆：`python tools/castsheet.py cast.chuhan out.jpg`

## 1. 开工前先问清楚

这些事没有固定答案，先问用户再动手：
- **音效**：要不要加，加在哪些地方（撞击、马蹄、箭雨……）。不问就默认只有 BGM。
- **BGM**：用哪首、片长大概多少。
- **配音**：不默认加，也不等用户提。自己先判断这部片配音会不会更好（有人物台词、有笑点、靠讲述推进的片子通常会；纯卡点燃剪通常不用），觉得好就问用户"要不要加配音"。用户说加，就按第 7 节的流程做；说不加，就只用字幕。
- **角色**：沿用角色库里已有的长相，还是要新人物、新朝代的服装。
- **署名**：印章和片尾页写什么账号名、第二行写什么；是不是商单（要不要加对方 logo）。右上角的「@账号名」角标默认不加，用户明确要求才加。
- **开头**：想用什么抓人（一个反常的事实、一个问题、最燃的一个画面……）。

## 2. 模块一览

| 模块 | 做什么 |
|---|---|
| `mapwar.world.World(cfg, data_dir)` | 按 `bbox` 截取真实地理做成宣纸底图；由**城池表 + 易手时间**逐帧推算各势力范围。范围可以是一省、一国、一洲 |
| `mapwar.mapshot.MapShot(world, sc)` | 地图镜头：斜视沙盘 ↔ 垂直全局；`'ink'` 宣纸水墨 / `'night'` 夜色水墨；城（易手换旗 + 墨环）、军队方阵（人数∝√兵力）、笔触箭头、日期、字卡；`ground_fx / overlay / post / top` 四个钩子。`sc['egg']={势力下标或军队名: 长相}` 把军队画成蛋蛋兵，`sc['fig_scale']` 调人数；势力表里给 `label=(r,g,b)` 可单独指定地图文字色 |
| `mapwar.field` | 垂直俯视战场：兵种字形、`mk()` 方阵、`Battle` 关键帧阵战、`Wedge` 骑兵凿穿、`Ring` 四面合围、箭雨、河、营帐 |
| `mapwar.eggfield` | **斜视角大头兵战场**：逐兵模拟（接战、骑兵冲击、溃逃）+ 俯视 ↔ 斜视连续运镜；`render()` 画模拟结果，`scene()` 画自己摆的一帧（主角可放大、可入夜、可举火把、开枪、大刀冲锋、蹲伏）；`set_looks()` 换两方长相 |
| `mapwar.eggfx` | 近现代战场零件：战壕、沙包、河、浮桥、木船、山丘、曳光弹、炮弹爆炸和弹坑、手榴弹、飞机。作为 `scene()` 的 `props / under / over` 传入 |
| `mapwar.qrig` / `qcostume` / `qdraw` | **Q 版角色**：关节骨架、表情（眼/眉/嘴/汗滴泪滴等符号）、服装零件（铠甲、大靠、靠旗、长袍宽袖、冠、冕旒、发髻、斗笠、兵器、道具；近现代军装、绑腿、军帽、短发、披风、步枪）、胡子（八字、络腮、胡茬点）和痣。一个角色 = 一份参数表。`qrig.head(..., P={'front': True})` 画正面大头 |
| `mapwar.qchar` | 角色的简便接口：`Q(c, x, 脚底y, 身高, 角色, 朝向, 姿势, t, 表情和关节微调…)`；`rider()` 骑马 |
| `mapwar.qhorse` | Q 版马：站、走、奔、扬蹄 |
| `mapwar.scenery` | 人物镜头的背景（`landscape('day'/'dusk'/'night'/'hall')`）、火焰烧穿转场 `burn()`、草/芦苇/营帐/篝火/雪/船/扬尘 |
| `mapwar.brand` | 成片署名：右下淡印章 + 片尾页；右上角「@账号名」角标默认不加，用户要求时传 `--corner` / `corner=True`；可在左上角加商单 logo（白底自动抠图），并压到适合上传的体积 |
| `mapwar.voice` | 配音（用户同意加才用）：edge-tts 在线生成旁白和角色台词，本地变声成蛋蛋人萌音，按实际时长排时间线，说话处压低 BGM。见第 7 节 |
| `mapwar.film.Film(shots, total)` | `still` 抽静帧 / `sheet` 总览图 / `part`、`render` 分段并行渲染 + 核对帧数 + 混音 |
| `mapwar.audio` | BGM 找重拍、看段落响度；合成低频重击、撞击、马蹄、箭雨（用户要音效时才用） |
| `cast/` | **角色库**：每个题材一个文件，存角色参数表。同一个人跨片子用同一份参数 |
| `mapwar.chars` / `mapwar.sil` | 旧做法：抠像贴图、生图剪影。只在用户点名要时用 |

细节写在各模块开头的注释里，先读注释再用。Q 版角色和大头兵战场的参数、姿势、写法见 `references/qchar.md`。

## 3. 一部新片的做法

1. **定题和史料。** 列出要演的阶段、关键战役、每方兵力、日期，核对出处。片子里只放结论，不放"号称""约""示意"这类修饰和出处。
2. **定地图范围。** 用 `tools/basemap.py` 试几个范围，选既装得下全部舞台、又不浪费画面的。`px_per_deg` 是纹理精度：范围小可以给大（100+），范围大要给小（20–40）；`reach`（控制半径，度）随范围等比放大。
3. **城池表 + 易手时间。** 势力范围完全由它推出来：每个关键地点一行 `(名, 经度, 纬度, 初始归属, 显示级别)`，再写 `flips` 什么时刻归谁。显示级别为 0 的点只当势力锚点。
4. **BGM 找拍、定时间线。** 用 `audio.onsets / loud_sections` 找重拍和段落，量出小节长度，所有时间按小节写。重拍处放最大的变化。**尽量从一个连续的段落顺着放**（比如从间奏起，铺垫段接上来，鼓点落在第一场大仗）；把响段直接拼到铺垫段，即使对齐了拍子，听起来也像断了一下。
5. **设计开头。** 前几秒要让人想继续看下去，手法按题材定，先拿最强的画面出来，不要黑屏等待。
6. **写地图数据**：军队路线（带兵力）、箭头、镜头分段、日期、字卡。
7. **设计战场。** 每场重要战役想清楚"它为什么赢"，再选表现方式：俯视阵战讲阵型和打法（`references/battle_recipes.md`），斜视角大头兵讲冲击力和主角。一部片里两种可以混用，不必全换。
8. **人物戏。** 角色从 `cast/` 取或新建；侧面全身能演动作和互动，正面大头适合表情特写（写法见 `examples/sidu/film.py` 的 `bust()`）。
9. **先抽静帧看**（`still`、`sheet`），再出 540p 预览，确认后出 1080p，最后过一遍 `mapwar.brand`（默认只有印章和片尾页；用户要求右上角角标时加 `--corner`）。有配音的片子，在做画面之前先把纯音频版（BGM + 配音）发给用户听。

## 4. 两种地图风格

- **`'ink'` 宣纸水墨**：浅底，势力是乘上去的淡彩，交界一道焦墨线。信息最清楚，适合大部分段落。
- **`'night'` 夜色水墨**：底图压暗，势力变成发光的晕染，城变象牙白，军队带火把光。适合夜里发生的事，或需要压抑肃杀的段落。
- 风格由 `sc['style'](t)` 逐时刻决定，可以按段落切换；白天转入夜时可以用 `scenery.burn()` 烧过去。势力颜色每方给 `ink` 和 `night` 两套，夜色那套更亮更饱和。

## 5. 做得好的地方（可借鉴的思路）

- **兵力看得见**：方阵人数 ∝ √兵力，几十万和几千人一眼能分出来；兵力变化直接体现在人数上，配标签"56万""28骑"。人多的一方在画面里也要真的显得多。
- **城池易手是节拍点**：换旗 + 墨环 + 颜色从城向外推开，压在鼓点上。
- **战场演"原因"而不是演"打"**：背水列阵、半渡而击、骑兵凿穿、四面合围……每场仗换一种打法。
- **大头兵战场不乱的办法**：远处的兵只画色块，近处才画脸；兵器用亮色、画粗；镜头放在冲锋方的侧前方，看得到脸；溃逃的一方转身后露出惊慌表情；主角放大一圈并加标志物（翎子、披风）。
- **撞击瞬间切特写**：大场面撞上的那一拍切到主角的近身动作（慢放、顿帧、冲击帧），再拉回全景，比一直看全景有力。
- **同一个角色跨片子长相一致**：辨识度来自固定的角色、固定的署名。
- **字要大、要清楚**：标题和字幕用粗宋体加描边；大战役标题横排砸到正中再缩到左上角；底部字幕放在约 y=960（再往下会被平台界面挡住）；每句至少停 2 秒左右。
- **避开平台界面**：抖音等竖屏刷横屏视频时，画面右侧约 12% 会被头像、点赞那一列挡住，重要的字不要放在右边。

## 6. 常见坑

- `cv2.getPerspectiveTransform` 只收 float32。
- 纹理太大（范围大 × `px_per_deg` 大）会被系统杀进程且不报错：降 `px_per_deg`；渲染后要核对帧数。
- 镜头不要拉出地图范围以外；全局镜头的 zoom 按范围宽度算。
- 地名标签太多会互相挡：只给重要城市显示名字（`keycity`）。
- 河流按 Natural Earth 的英文名加粗；古今河道不同时用 `river_filter` 画细现代河段、`extra_rivers` 补古河道。
- Q 版角色的角度：0 = 朝下，正 = 朝前。挥兵器前先抽一帧确认方向。
- 穿长袍的角色，前臂默认画在头的下层，抬手时不会挡脸；需要手在脸前（比如抱人）时传 `arm_under_head=False`。
- 靠旗这类大背饰在翻腾、冲刺时要隐藏（`flags=False`），只在站定和亮相时出现，否则画面乱。
- 斜视角战场的 `simulate()` 约 5 秒，每个渲染进程各算一次即可，结果是确定的。
- 切点闪白这类效果，函数的默认值要让它"不闪"；默认值写成 0 秒前刚闪过，会让整段画面一直发白。
- 势力颜色偏灰偏淡时，自动算出来的地图文字也会发灰看不清，给这一方单独指定深色 `label`。
- 正面画法只对 `qrig.head()` 和传了 `front=True` 的部件生效；新加的帽子、发型要同时写正面分支，否则正面特写会出现侧面的帽檐。

## 7. 配音（用户同意加才做）

什么时候问：开工前自己判断，这部片有人物台词、有笑点、或者靠讲述推进时，配音通常比纯字幕好，就问用户要不要加。用户同意才走下面的流程。

用的是 `mapwar.voice`：`edge-tts` 调微软 Edge 的在线神经语音（免费、不用 Key、要联网，不是本地模型），逐句生成后在本地用 ffmpeg 裁静音和变声。

```
from mapwar import voice
from mapwar.audio import Mix
VOICES = {'N': voice.NARRATOR,                                             # 旁白：低沉男声 YunjianNeural，不变声
          '金兵': voice.cute('zh-CN-YunxiaNeural', 1.20, '+15%', '+10Hz'),  # 蛋蛋人萌音：k 越大越尖
          '宋兵': voice.cute('zh-CN-XiaoyiNeural', 1.24, '+10%', '+15Hz')}
LINES = [('a4', 'N', B(6), '没过两年，野狐岭，金军主力，全崩！', '没过两年  野狐岭  金军主力全崩'),   # 数字：最早从这一秒开始
         ('a5', '金兵', None, '老板，咱家没啦！', '老板，咱家没啦！'),                               # None：紧跟上一句
         ('b1', 'N', '+0.5', '第二个，花剌子模。', '第二个：花剌子模')]                              # '+0.5'：停 0.5 秒再说
tl = voice.build(LINES, VOICES, 'vo')                 # 生成 vo/*.wav 和 vo/timeline.json，打印每句的实际起止时间
mix = Mix(bgm, total); voice.lay(mix, tl, 'vo', keep=[(0, T0)])   # 说话处压低 BGM 并铺人声；之后再 mix.add 音效
```

做法和顺序：
1. **先写完整文案给用户看**：旁白和角色台词分开标，每句配一条字幕（字幕可以比台词短）。
2. **定音色**：旁白用 `voice.NARRATOR`；角色台词用 `voice.cute(底音, k)` 变成萌音，一个角色固定一种，k 取 1.16–1.28。拿不准就用 `python -m mapwar.voice "台词" out.wav 音色 k` 试听。
3. **`voice.build` 排时间线**：每句的开始时间按实际录音长度顺延。想卡在拍子上的句子给绝对时间，其余写间隔。打印里出现 `LATE` 说明这句被上一句挤晚了，要删字或挪拍子。
4. **混音**：`voice.lay` 要在加音效之前调用；开头有歌词的时段放进 `keep`，不压低。重音效不要压在关键字上。
5. **先把纯音频版发给用户听**，语速、笑点、萌音尖细程度确认后再做画面。
6. **画面跟着时间线走**：片子里用 `voice.load('vo')` 读时间线，`voice.at(tl, t)` 取此刻正在说的那句，画底部字幕或角色气泡。台词改了就重跑 `build`，画面的时间点从时间线里取，不要写死。

注意：
- 语速宁慢勿快，句子之间留气口；用户嫌快时把 `rate` 降一档、间隔加大，片长跟着拉长。
- 萌音的短句（两三个字）单听不容易听清，必须配字幕或气泡。
- 配音是 AI 合成的，交付时告诉用户；用户想自己配的话，把 `vo/<id>.wav` 换成同名文件再重跑混音即可。

## 8. 参考
- `references/directing.md`：**导演手册**。每部片开拍前先定母题、色彩脚本、反复出现的局部、声音留白；镜头规则（人必须动、同场戏按拍切景别、跟拍、特写插入、分屏）。做人物/剧情片前必读。

- `examples/chuhan_q/`：古代题材成片（Q 版人物 + 地图上的古代蛋蛋兵 + 俯视阵战 + 大头兵撞阵和夜间突围 + 动作特写 + 侧面全身的情感戏）。`film.py` 总时间线，`fight.py` 动作编排的写法，`breakout.py` 自己摆兵的写法。
- `examples/sidu/`：近现代题材成片（地图上的红军/国民党军蛋蛋兵 + 战壕沙包对射、大刀冲锋、渡河 + 正面大头特写）。`film.py` 总时间线，`battles.py` 战场镜头，`geo.py` 地图数据，`mix.py` BGM 加少量音效。
- `examples/chuhan/scenario.py`：同一题材的地图数据和五种俯视战场（人物部分是旧的贴图做法，不要学）。
- `cast/chuhan.py`：楚汉角色库（演义戏曲扮相）；`cast/sidu.py`：四渡赤水角色库（红军、国民党各军、领袖）。
- `references/qchar.md`：Q 版角色、马、动作编排、大头兵战场的用法。
- `references/battle_recipes.md`：俯视战场打法和近现代斜视角战场 → 代码写法对照。
- `references/lessons.md`：做这类片子时用户反馈过的问题和偏好。
- `references/stills/`：成片静帧和底图样张。
