# 战场打法 → 写法对照

俯视战场的坐标就是屏幕像素（中心约 960,560），`FCam` 可推拉。时间都是镜头内的秒（lt）。
下面每条是"这一仗赢在哪 → 画面上怎么让人看出来"。都只是起点，按史料改。

## 基本零件
```python
U = [mk('shield', 'H', 0, 0, depth=2, width=34, path=[(0, 640, 560), ...], face=[(0, 0)], cas=[(0, 0), (1.7, .16)], order='front'),
     mk('cav', 'H', 0, 0, 6, 4, sp=42, path=[...]),            # 骑兵间距 40 左右
     mk('spear', 'Z', 0, 0, 7, 10, shape='wedge', ...)]        # shape: block / wedge / crescent / ring
B = Battle(U, dur)                                             # 预演一次后缓存
fr = B.draw(c, lt, SIDES)                                      # fr[i]['c'] = 第 i 个方阵当前中心，用来挂旗、挂标签
```
- `path` 阵心轨迹；`face` 朝向（不给就朝运动方向）；`cas` 累计伤亡比例（倒下的人留在原地成墨点）；`scat` 溃散半径（>18 时兵会转身乱跑、丢掉兵器）。
- `order='front'` 让前排先倒——正面接战的盾阵/前锋用它。
- 一个关键时刻 `tF` 对准重拍：抖动 `FCam(..., hits=[(tF, 22)])`、闪白 `finish(..., hits=[tF])`、大字 `X.slam()`。

## 打法示例（examples/chuhan 里都有实现）

| 打法 | 画面要点 | 用到 |
|---|---|---|
| **背水列阵 + 奇兵袭营** | 一侧是宽河，本方盾-矛-弓三层背河列阵；敌方多个方阵压上；一队骑兵从画面边缘绕到敌营，旗子一面面换色（换旗瞬间旗放大回弹） | `river`、`camp`、`banner` 换色、骑兵长路径 |
| **佯败诱敌 + 决水半渡** | 前锋先退（face 翻转）；敌军追入河道；河宽从窄突然变宽、一道白色洪峰从上游扫下；河中的方阵 `cas→1`、被冲向下游；已渡的被两翼骑兵包住 | `river(w=函数)`、分三段写敌军（已渡/河中/未渡） |
| **骑兵锥形凿穿** | 锥形骑队从左横穿一片密集营地；近者倒、稍远者四散、营帐被掀翻；骑兵身后拖尘 | `Wedge(rows, nreg, dur, speed=...)` |
| **多层阵 + 两翼纵击** | 中军先接战、后退（"不利，却"），两翼方阵转向斜插，中军再压上；四个阶段各配一句字幕 | `face` 关键帧转向、`cas` 分段 |
| **四面合围** | 中间一方阵，外圈上千人由远及近收拢，被围者由外向内倒下；适合夜色 | `Ring().draw(c, k, lt, inner, outer)` |

## 还可以扩展的
- **新兵种**：照 `field.unit()` 加一个分支——俯视下只需"轮廓 + 一个识别特征"（象兵=大椭圆+鼻、投石机=方框+长臂、火器兵=短管+火光、船=梭形）。
- **地形**：山口（两侧画暗色山体收窄通道）、城墙（粗墨线 + 垛口）、火攻（`mapshot` 里的火焰画法可以搬到战场）、雪地/沙漠（换 `ground()` 的底色）。
- **骑射回旋**：骑兵沿椭圆 `path` 绕敌阵，边走边 `volley`，敌阵外缘逐渐 `cas` 上升——适合游牧骑兵题材。
- **攻城**：城墙一侧守军放箭，攻方云梯（短线）贴墙，城门处 `cas` 集中，破门后旗子换色。

## 近现代：斜视角战场的写法（examples/sidu/battles.py）

近现代的仗用斜视角大头兵 + `eggfx` 零件来演，"赢在哪"同样要让人一眼看出来：

| 打法 | 画面要点 | 用到 |
|---|---|---|
| **阵地对射 / 强攻不下** | 守方蹲在沙包、战壕后开火，曳光弹横穿，攻方冲到一半倒下一片；炮弹落点炸开、留弹坑 | `sandbag_line`、`trench`、`fire`、`tracers`、`blast` + `crater` |
| **冲锋夺关** | 攻方大刀、刺刀冲上山口，手榴弹先落进敌阵，守军转身溃逃 | `dao`、`grenade`、`hill`、state=2 溃逃 |
| **渡河** | 河 + 浮桥或木船，队伍一列列过河；夜渡压暗、只留火光 | `river`、`bridge`、`boat`、`night=True` |
| **大军合围** | 四面敌军压上 + 飞机掠过，中间一小簇人，配兵力对比大字 | `plane`、`scene` 只摆四周 |

镜头里的标签要贴在兵的屏幕位置上：`eggfield.px(cam, 世界坐标)` 换算成画布坐标。
