# 导演手册：每部片是一部电影，不是一组配了字的图

用户的要求（原话）：「不是让你复刻他镜头，而是让你像一个导演一样，这每部影片就相当于你的电影。」
参考片只借技术（人要动、景别要变），拍法自己定。

## 开拍前先定四件事（写进分镜，发给用户）
1. **母题**：一件贯穿全片的东西，开头和结尾各出现一次，意思相反。例：奈德片的寒冰——开场他举剑行刑，结尾同一构图，跪着的是他。
2. **色彩脚本**：颜色随剧情走，不用旁白说情绪。例：越往南越红（北境冷灰蓝 → 极乐塔第一次见红 → 贝勒大圣堂红金）。
3. **反复出现的局部**：选一个身体部位或道具反复拍特写。例：手（接婴儿、垂下、递遗诏、被反绑）。
4. **声音留白**：全片最重的一下放在哪个小节，那一下之后音乐停不停。

## 镜头规则
- **人必须动**：走、跪、举手、扑出去都逐帧画（姿态插值 + 走路循环），不能是「静帧 + 慢推」。检查方法：10fps 抽帧算相邻帧差，中位数应明显高于纯慢推。
- **同一场戏时钟连续，按拍切景别**：远景交代位置 → 中景看动作 → 特写看反应。切镜头时动作不重来。
- **跟拍**：人走路时镜头跟着走，背景分层视差。
- **道具/局部特写插入**：每场至少一个（书页、撕开的纸、匕首、手）。
- **人小厅堂大**：大场面把主角拍小，只有做选择的瞬间才推到脸上。
- **分屏**：两人对峙、各说一句时用斜线分屏。
- **匹配机位再变形**：要把真人戏变成另一种画法（如彩窗），先把机位对齐到同一构图再叠化。
- **重拍给动作，不给转场**：战锤砸下、长矛调转、剑落，都卡在小节线上；震动和闪白只给这些点。
- **字**：小字幕讲事，金色大字只给台词和结论；一屏最多两行，约 0.25 秒/字。

## 实现（/home/ubuntu/asoiaf）
- `stage.py`：Scene（分层背景 + 每帧 cairo 画人 + 每帧打光 + 前景层）、kf() 关键帧、walk() 走路循环、Shatter 碎裂。
- `baelor2.py`：一场戏的完整写法（场景构造 + 人物时间函数 + 镜头表）。
- `film2.py`：整片时间线（SETS / SHOTS / 字幕 / 闪白震动 / 音频静音）。
- `wmap2.py`：有山体阴影的倾斜沙盘地图。
- `shots.py` 设 `NOFIG=True` 可得到不带人的背景板。

## v3 补充（用户看完奈德 v2 后的反馈）
- **前面不能慢热，后面可以慢**。前 3 秒必须是全片最狠的画面加一句话的悬念（结局先行），不要从「很久以前」讲起。头 4 小节按半小节甚至一拍一切；慢镜头、长镜头留给后段。
- **冷开场的做法**：用同一构图的两个镜头硬切（匹配剪辑）把首尾呼应压进前 3 秒，例如「他举剑（冷色）→ 同一把剑举向他（红色）」；接着用 4–5 个一拍一切的倒带快剪预告全片最有力的局部；再出片名。
- **别全是侧面平视**。每场戏至少换一次机位高度：俯拍（人小、局势大，如长矛围成一圈）、仰拍（权力、压迫）、大特写（眼、手）、前景遮挡（失焦的柱子/树干，视差比主体大）、斜角构图（局势失控时）。
- **镜头长短要有对比**：信息段逐拍跳切（同一场景连续推近不同对象），情绪段留长镜头。
- **画面接画面**：闪回用一拍的插入镜头（黑牢里闪回婴儿的手），比字幕解释更有力；地图到场景之间用甩镜。
- **地图**：用户给了参考图就按它的海岸线和画法重画（提取陆地 mask，自己渲染羊皮纸、墨线山、地名），不要用自己想象的轮廓，也不要直接把参考图当素材。地图做成被提灯照亮的桌面沙盘，才能和暗调人物镜头接上。
